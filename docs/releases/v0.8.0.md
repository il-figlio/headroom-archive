Headroom's first downloadable release adds Sparkle self-updates from this private repository.

- Check, download, verify, install, and relaunch from inside Headroom.
- Automatic update checks and installation can be controlled from the panel's settings menu.
- Uses the existing GitHub CLI login on each Mac. No shared GitHub token ships in the app.
- Appcast and update archive are signed with Headroom's Sparkle Ed25519 key.
- Developer ID signed and notarized by Apple.
- Universal macOS app for Apple Silicon and Intel, macOS 13 or later.
- Includes the reservoir icon, memory and disk monitoring, app quit controls, trends, recommendations, and optional agent/quota widgets.

Install Headroom.app in /Applications. Install GitHub CLI and run gh auth login with access to il-figlio/headroom on each Mac before checking for updates.
