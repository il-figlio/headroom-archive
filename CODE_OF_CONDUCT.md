# Code of conduct

Headroom follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, and keep discussion about the work.

## Reporting

If someone's behavior in this project's issues, pull requests, or discussions
is a problem, report it privately to the maintainer, @il-figlio:

- use GitHub's **Report content** option on the comment or issue, and
- for anything you'd rather not post publicly, open a private report under
  this repository's **Security** tab and start the title with "Conduct:".

Reports are read by the maintainer only and handled as described in the
Contributor Covenant's enforcement guidelines, from a warning up to a ban
from the project.
